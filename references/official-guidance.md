## 模型与参数

- `gpt-5.6` 别名路由到旗舰能力模型 `gpt-5.6-sol`。
- Responses API 支持为 GPT-5.6 设置 `reasoning.effort`：`none`、`low`、`medium`、`high`、`xhigh`、`max`。
- `medium` 是平衡起点；`low` 适合延迟敏感任务；`max` 应用于最困难、质量优先的任务并通过评测验证。
- Pro mode 通过 `reasoning.mode: "pro"` 启用，不使用独立的 Pro 模型名称。推理模式和推理强度分别设置。
- `text.verbosity` 可设为 `low`、`medium` 或 `high`，用于请求级默认详细程度。

## 提示词原则

1. 使用更精简的提示词；删除重复指令和无关示例，每条规则只写一次。
2. 只暴露任务相关工具，并保持工具描述精确、简短。
3. 明确回答/审查与修改/构建请求的权限差异，以及外部、破坏性、付费和扩范围操作的确认要求。
4. 用参数控制默认长度，用提示词规定任务特定的必需内容与结构。
5. 用可观察的写作行为定义语气，不只使用“友好”“专业”等宽泛标签。
6. 使用 Pro mode 时仍写结果导向的提示词：目标、背景、限制、证据、成功标准和输出格式。
7. 不需要在提示词中要求模型“更努力思考”、进入 Pro 或生成多个内部候选答案。
8. 精简或迁移提示词时逐组修改，并在代表性任务上比较成功率、完整性、证据、令牌、延迟和成本。
